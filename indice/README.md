# El Índice

**Quién ya lo hizo.** No es un directorio — es un enrutador.

## Estado: vacío

**0 personas ofrecidas.**

## La diferencia con un directorio

Un directorio lista gente: nombre, empresa, cargo, contacto. LinkedIn ya lo hace mejor y no necesitas otro.

Un enrutador lista **transiciones**, no personas:

| Transición | Cuántos la hicieron | Disponibles para conversar |
|---|---|---|
| Chile → Canadá, minería | 0 | 0 |
| Chile → EE.UU., consultoría | 0 | 0 |
| Operaciones → finanzas | 0 | 0 |
| Corporativo → emprender | 0 | 0 |
| Volver a Chile | 0 | 0 |

Preguntas por **la ruta**, no por la persona. Y quien contesta lo hace porque se ofreció para esa ruta específica, no porque alguien lo encontró en una lista.

## El problema real que resuelve

No es "no conozco a nadie". Es **"no me atrevo a molestar"**.

Todos conocemos a alguien que ya se fue a Canadá. Poca gente le escribe, porque hace ocho años que no se hablan y pedirle media hora se siente como abusar.

El Índice elimina eso: **el que está acá ya dijo que sí.** Se ofreció para esa conversación específica. Escribirle no es abusar — es usar algo que él puso a disposición a propósito.

## Cómo entrar

En el [formulario de entrada](../../../issues/new?template=00-entrada.yml), marca:

> *"Quiero aparecer en El Índice como alguien dispuesto a conversar con quien esté en mi misma transición."*

No publicamos tu contacto. El contacto pasa por el issue, así que tú decides si respondes y nadie obtiene tu correo por estar en una lista.

## Las reglas de la conversación

Para el que pide:
- Llega con la pregunta hecha. "¿Me puedes contar de Canadá?" es una hora; "¿el reconocimiento de APEGA te pidió exámenes técnicos?" son cinco minutos
- Una conversación, no una relación de mentoría, salvo que salga sola
- Agradece con un aporte al repo, no con un café que nunca va a pasar

Para el que responde:
- Puedes decir que no, o no responder. Ofrecerte no te obliga a nada
- Sal del Índice cuando quieras, sin explicar
